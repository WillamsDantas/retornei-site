# Retornei · página de vendas

Página estática (HTML, CSS e JavaScript sem dependências) publicada pelo GitHub Pages.

- `index.html`: página única, com CSS e JS no próprio arquivo. As cores e medidas ficam em variáveis no `:root`, com os mesmos nomes das variáveis do Figma ("Retornei · cores" e "Retornei · medidas").
- `img/`: telas reais do app em WebP e a imagem de compartilhamento (`og.jpg`).
- `fonts/`: Inter (licença OFL em `fonts/OFL-LICENSE.txt`).

Todos os botões levam para https://retornei-app.web.app/ e repassam os parâmetros UTM da URL.
